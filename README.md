# The World in One Day — Tuesday 24 November 2026

![make.fun](https://img.shields.io/badge/make.fun-news--image--20261124-blue)
![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Python 3.13](https://img.shields.io/badge/python-3.13-blue.svg)

One image that sums up the world's news of Tuesday 24 November 2026:
96 drones over Ukraine in one night, Kyiv defending its Libya strike,
and chip shares rocketing as Jensen Huang returns to Nvidia — plus 30
more stories from the same day, a UTC timeline, the day in numbers, a
dotted world map, and a date check that names the Monday news left out.
Every story on the page happened, or was first reported, on that one
Tuesday. The artwork is drawn in code; it is not a photograph.

## Run

```sh
python3 main.py
```

The program copies `entry.png` (1024 × 1024, under 1 MiB) to
`$MAKEFUN_OUTPUT_DIR`, or `/output` when that variable is not set.
Standard library only, no network, deterministic: two runs write the
same bytes.

## Files

- `entry.png` — the image itself
- `main.py` — the copier program
- `LICENSE` — MIT
